STLs are oriented for printing. 

## Recommended print settings:
- 3 walls
- 3 layers top and bottom
- 20% infill
- Organic/tree supports

## Hardware needed
- (4) M3 threaded inserts
- (4) M3x6 screws. Cap head screws look nice on it
- (4) M2.5x8 screws
- (4) M2.5 nuts

## How to assemble
### Step 1

Install the threaded inserts into the holes for them on the back

<img src="Display install.jpg" width="300"/>

Glue the bracket to the ESP32 holder as shown. Cyanoacrylate glue will work fine. 

- Note: the bracket supplied in the STLs is properly sized. Glue the long side of the bracket to the ESP32 holder, butted against the bottom.
- The bracket should set approximately 3mm above the top side of the ESP32 holder.

<img src="Bracket Mount.jpg" width="300"/>

<img src="Bracket Mount 2.jpg" width="300"/>

Depending on printer tolerance, you may need to drill the holes around the display opening out to 2.5mm

Install the M2.5x8 screws and install the display using the M2.5 nuts.
* The wrench STL supplied is sized such that you should be able to insert the nut, set it on the bottom of the case and slide it in to help with installing the lower nuts. You can do them by hand, but they're difficult to install.

<img src="Display install.jpg" width="300"/>

<img src="Display install 2.jpg" width="300"/>

Place the ESP32 controller on the holder, with the rear of the ESP32 under the bracket that you installed earlier. The bracket keeps the rear of the controller in place, and works with the nubs on the back panel to position it such that the power cable can be plugged into it.

<img src="Controller install.jpg" width="300"/>

Finally, install the back panel with the M3x6 screws

<img src="Back Panel.jpg" width="300"/>
